# 손으로 확인하는 점검표

자동 검사(`node tests/run.mjs`)는 머리 없는 브라우저에서 돈다. 카메라 · 두 기기 · 음성 인식 · 실제 소리처럼
**사람이 기기를 들고 봐야 하는 것**은 여기 적힌 순서로 확인한다. 새 판을 배포한 뒤 한 번씩, 또는 관련 기능을 고쳤을 때 한다.

| 표시 | 뜻 |
|---|---|
| ☐ | 아직 · 해 보고 ☑ 로 바꾼다 |
| 🅰 | 교육생 기기(태블릿 · 노트북) |
| 🅱 | 교관 기기(휴대폰 · 다른 태블릿) |

---

## 1. 새 판 받기 · 새 버전 알림

- ☐ 앱을 열어 둔 채 새 판을 배포한다 → 30분 안(또는 다시 열 때) 화면 위에 **'새 버전이 있습니다 [새로고침]'** 띠가 뜬다
- ☐ [새로고침] 을 누르면 새 판으로 바뀐다(🧰 도구 → 🩺 진단 기록 의 '판' 번호가 올라간다)
- ☐ [나중에] 를 누르면 띠가 사라지고 앱은 그대로 쓴다
- ☐ 홈 화면 앱(PWA)으로 연 경우에도 같다

## 2. 소리

- ☐ SOUND 를 켜면 로터 소리가 난다 · 토크를 올리면 커진다(70 → 100%)
- ☐ Bell 엔진 고장 → ENG OUT 경고음 · HORN MUTE 로 꺼진다 · 경고가 풀렸다 다시 걸리면 또 울린다
- ☐ 경고음이 울리는 동안 로터 소리가 반으로 줄어든다
- ☐ 흰수리 RA 콜아웃(⚙ 설정 켬) — 500 · 100 · 50 ft 를 내려가며 말한다
- ☐ TCAS(🌙 ENV 교통량 3대) — 'Traffic, traffic' · 흰수리는 'Climb, climb' / 'Clear of conflict'
- ☐ iPad Safari: 첫 화면을 한 번 누른 뒤 소리가 난다(브라우저가 첫 터치 전 소리를 막는다)

## 3. 무전 · 관제 · 리드백(음성 인식)

- ☐ **Bell**: 오디오 패널 MIC 1 · GNS 430 COM 을 가까운 공항 TWR 로 → PTT 누르고 놓으면 관제가 답한다(음성 + 알림)
- ☐ **흰수리**: CDU AUDIO → COM1 MIC 고르기 → 같은 화면 **🎙 PTT** 를 누르고 놓으면 관제가 답한다
- ☐ 흰수리 MIC 를 U/VHF · VHF-FM 로 바꾸면 송신 잡음만 나고 관제는 답하지 않는다 · MIC OFF 면 '송신 안 됨'
- ☐ 조이스틱 설정에서 **PTT** 를 단추에 배정 → 누르는 동안 송신(두 기종)
- ☐ 관제 지시 뒤 30초 안에 PTT 를 누르고 영어로 리드백 → '리드백 정확' 또는 'negative, read back …'(Chrome · Edge)
- ☐ 마이크 권한을 거부하면 리드백 확인 없이 그냥 받는다(앱이 멈추지 않는다)

## 4. 교관 화면 — 같은 기기

- ☐ 🧰 도구 → 🧑‍✈️ 교관 화면 → 새 탭에 교관 화면 · '● 교육생 창과 이어짐'
- ☐ 고장 단추 → 교육생 창에서 바로 걸린다 · 다시 누르면 풀린다
- ☐ Bell 일 때 **연료 · 무게(Bell)** 칸이 보인다 → 연료 20 gal · '뒤로 쏠림' → 교육생 W&B 창 · 성능이 바뀐다 · CG 한계 밖이면 빨강

## 5. 교관 화면 — 다른 기기(QR · 서버 없음)

같은 와이파이(또는 같은 휴대폰 핫스팟)에 두 기기를 둔다.

- ☐ 🅰 🧰 도구 → 📱 교관 기기와 잇기 → **① 연결 요청** → QR 이 뜬다
- ☐ 🅱 교관 화면(주소 끝 `?ios=1`) → **② 수락 — 교육생 QR 찍기** → 카메라 권한 허용 → 🅰 의 QR 을 비춘다
- ☐ 🅱 에 QR 이 뜬다 → 🅰 **③ 교관 QR 찍기** → 🅱 의 QR 을 비춘다
- ☐ 두 기기 모두 '이어짐' · 🅱 에서 고장 · 바람 · 메시지가 🅰 에 걸린다 · 🅰 의 고도 · 속도가 🅱 에 보인다
- ☐ 카메라가 없거나 막히면 `<details>` 안의 글자 코드로 붙여 넣어도 이어진다
- ☐ 회사 와이파이(기기끼리 막힌 망)에서는 이어지지 않을 수 있다 — 핫스팟으로 다시 해 본다

## 6. 저장 · 진단

- ☐ 📋 강평 → 비행 저장 → 앱을 닫았다 다시 열어도 목록에 남는다(이제 IndexedDB · 30개까지)
- ☐ 예전 판에서 저장한 비행이 새 판에서도 보인다(처음 열 때 옮긴다)
- ☐ 🧰 도구 → 🩺 진단 기록 → 저장 공간(사용량 / 할당) · 타이머 · 오류가 보인다 → 📋 복사 가 된다
- ☐ ⚙ 설정 → 모든 설정 내보내기 → 다른 기기에서 들여오기 → 시나리오 · 저장 비행이 옮겨 간다

## 7. 화면 · 지도

- ☐ 좁은 창(휴대폰 세로 · 4분할)에서 지도 아래 단추줄이 넘치지 않는다 · **⋯** 를 누르면 CLR · T-CUT · HOLD · INHIB · 방위 · 🔒 가 둘째 줄에 나온다
- ☐ 밤(🌙 ENV 야간) 산 뒤 공항 불빛이 산에 가려 보이지 않는다 · 산을 넘으면 보인다
- ☐ Bell 외부 시점(EXT) — 2날개 로터 · 스키드 · 왼쪽 꼬리로터 · 흰 동체에 파란 띠
- ☐ 저수지 · 간척지 · 하구 위 낮은 땅에 내려앉아도 '착수' 로 판정되지 않는다 · 바다 위는 착수

## 8. 조이스틱 · 키보드

- ☐ 조이스틱을 꽂으면 알린다 · 축(사이클릭 · 페달 · 컬렉티브)을 잡고 단추를 배정한다
- ☐ PTT · FORCE TRIM · 외부 시점 · 시야 둘러보기 가 누르는 동안 / 한 번 누름으로 맞게 듣는다
