1. 화면 구성

  • 처음 켜면 3분할입니다 — 좌 PFD · 중 MAP · 우 CDU. 상단 ⿰ 2분할 버튼으로 두 창만 볼 수도 있고, 그 선택은 저장되어 다음에도 그대로 열립니다.
  • 각 창 모두 PFD / MAP / CDU 탭으로 전환. 다른 창에 있는 창을 고르면 두 창이 자리를 맞바꿉니다.
  • 같은 창을 두 패널에 겹쳐 둘 수는 없습니다 — 다른 창에서 고르면 서로 자리를 맞바꿉니다. Flight Plan 은 CDU 창의 한 화면이라 CDU 와 겹치지 않으며, 2D 지도(MAP)와 3D 지도(3D)만 서로 다른 창이라 나란히 둘 수 있습니다.
  • Flight Plan은 CDU 가 있는 창에서 열립니다. CDU 를 좌측에 두었으면 좌측 창이 Flight Plan 으로 바뀌고, BACK 을 누르면 그 자리가 다시 CDU 가 됩니다(다른 창은 그대로).
  • 전체화면: CDU·Flight Plan 하단 Full, MAP 상단 FULL 버튼. 되돌아올 때는 같은 자리의 HALF.
  • 경계선의 ◀▶ 그립을 드래그하면 분할 비율 조절(자동 저장). 3분할에서는 그립이 두 개라 좌·중·우 폭을 각각 잡을 수 있고, 각 경계선은 맞닿은 두 창끼리만 크기를 주고받습니다. 그립을 더블탭하면 기본 배분으로 되돌아갑니다. ⟳은 새로고침.

2. 기본 비행 (시뮬레이션)

  • 시작 — 처음 열면(비밀번호 다음) 출발 공항을 고르는 창이 뜹니다. 지도의 ICAO 공항 목록이며, ICAO·이름으로 걸러 찾을 수 있습니다(Enter = 맨 위). 고르면 그 공항 지면에 멈춰 서고, 건너뛰면 송도에서 시작합니다. 같은 탭에서 새로고침하면 다시 묻지 않고, 브라우저를 새로 열면(비밀번호를 다시 묻는 때) 지난번 상태가 남아 있어도 다시 묻습니다 — 그때 건너뛰면 지난 자리에서 이어 갑니다. GPS 는 꺼진 채 시작합니다(기기 위치를 묻지 않습니다) — 실비행에 쓰려면 지도의 GPS 버튼으로 켭니다.
  • MAP 하단 ▶ FLY로 시작(다시 누르면 PAUSE), RESET 초기화, CLR 비행계획 삭제. 3D 창 오른쪽 위(EXT 아래)에도 같은 ▶ FLY / ⏸ PAUSE 버튼이 있습니다.
  • 🔇 / 🔊 SOUND(3D 창 FLY 아래): 로터 소리를 켜고 끕니다. 땅에 있으면 이륙 전 소리, 바퀴가 떨어지면 이륙 후 소리가 나고, 뜨고 내려앉을 때 두 소리가 2.5초에 걸쳐 겹쳐 바뀝니다 (LIGHT ON WHEELS 에서는 이륙 후 소리를 조금 미리 섞습니다). PAUSE 면 소리도 잦아듭니다. 소리 크기는 토크를 따릅니다 — 토크 0% 에서 70%, 100% 이상이면 100%. 켜 둔 채 앱을 새로 열면, 브라우저 규칙상 화면을 한 번 누르거나 키를 누를 때 소리가 납니다.
  • 3D 창: 각 창의 탭에 3D 가 있습니다. 한 창을 MAP, 다른 창을 3D 로 두면 2D 지도와 3D 지도를 나란히 볼 수 있습니다(3분할이면 가운데 2D · 우측 3D 처럼). 3D 지도는 한 벌을 옮겨 쓰므로 타일을 두 배로 받지 않습니다. 3D 창을 쓰는 동안에는 지도 툴바의 3D(2D 위에 겹치기) 버튼이 동작하지 않습니다 — 겹치면 2D 창이 빈 화면이 되기 때문입니다. 창을 다른 것으로 바꾸면 3D 지도는 원래 자리(2D 위 겹치기)로 돌아갑니다.
  • ⿲ 3분할(좌측 상단 탭): 넓은 화면에서 PFD·MAP·CDU를 한 번에 봅니다. ⿰ 2분할을 누르면 되돌아갑니다. 각 패널의 탭으로 어떤 창을 둘지 바꿀 수 있고, 같은 창을 고르면 서로 자리를 맞바꿉니다.
  • ⛶ 단독(각 창 탭 줄의 오른쪽 끝): PFD 단독 · MAP 단독 · CDU 단독 — 그 창 하나만 화면 가득 띄웁니다. 계기비행 연습처럼 PFD 만 크게 보거나, 지도·CDU 를 넓게 볼 때 쓰십시오. 버튼을 한 번 더 누르면(또는 떠 있는 ✥ HALF · 상단 막대의 ✕) 들어가기 전 배치 그대로 돌아옵니다. 단독 중에는 상단 막대에서 다른 창으로 바로 넘어갈 수 있습니다.
    ⛶ 3D Only(오른쪽 창 탭 줄 — 2분할·3분할 모두) — 3D 지도를 화면 가득 띄웁니다. 빠져나갈 때는 위 가운데의 ✥ HALF.
    계기 크기 − / +(3D 단독 화면, 계기 버튼 아래) — 왼쪽 위 PFD 계기를 60 % ~ 160 % 사이로 10 % 씩 줄이고 키웁니다(크기는 기억됩니다).
    LOWER(UPPER 옆 탭) — 실기 하부 콘솔: 왼쪽 열 ⑰ AHRS · ⑯ AFCAU(AUTO TRIM · TRIM FEEL · AP1/AP2) · ⑮ 비디오 컨버터 · ⑭ 비상부주(EMERG FLOATS) · ⑬ 호이스트 · ⑫ CPI CONTROLLER · ⑪ PA, 오른쪽 열 ⑥ FUEL(X-FEED · FT1/BP1 · XFER · FT2/BP2 · AUX1/F5/AUX2 XFER) · ⑦ U/VHF-AM/FM · ⑧ VHF-FM · ⑨ AVCS · ⑩ MPP · NOSE WHEEL LOCK · PARKING BRAKE. 사각 버튼은 누르면 들어가 글씨가 켜지고(한 번 더 누르면 나옴), 흰 키는 누르는 동안만 들어갑니다(FLOATS TEST 는 BTL 표시등). 조작법·RESET·ZONES 는 UPPER 와 같습니다. 연동: PARKING BRAKE 레버 RELEASE · EMER · SET → SIM 브레이크(SET 은 파킹 — 스페이스 두 번과 같고 레버도 따라 움직임 · EMER 는 비상 브레이크로 세기가 스페이스 휠 브레이크(6 kt/s)와 SET(12 kt/s) 사이인 9 kt/s, PFD 에 EMER BRAKE) · FUEL 패널 → SYSTEM 창 Fuel(BP · TP)과 Aircraft Status(Crossfeed · 이송 펌프 · E-AUX) · AFCAU AP1/AP2 OFF → SYSTEM 창 AFCS 레인 OFF. 나머지는 위치만 갖고 있고 연동을 하나씩 붙여 갑니다.
    UPPER(CDU · MAP · 3D 옆 탭) — 실기 상부 콘솔(WIPER · VAPOR VENT · TRAINING · ECS · 조명 · APU · 전원 · ANTI ICE)을 한 창에 띄웁니다. 토글은 글자 쪽을 누르면 그 위치로 갑니다 — 윗글자(OFF 등) 쪽 → 위, 아랫글자(ON 등) 쪽 → 아래, 3단의 옆 글자(ALL · AUTO 등) → 가운데. 노브는 위치 글자를 누르면 그 위치로 바로, 노브 몸통의 왼쪽 절반 반시계 · 오른쪽 절반 시계(휠도 됨) · 오른쪽 아래 ZONES 를 누르면 터치 영역이 테두리로 보입니다 · 덮개 스위치(TRAINING · FIRE EXTGH RESERVE)는 덮개를 먼저 열고(닫으면 제자리로) · CHIP DETECTOR TEST 와 EMB RST 는 누르는 동안만 · APU FIRE EXTGH T-핸들은 눌러 당기고 다시 눌러 넣습니다. 위치는 저장되고, 오른쪽 아래 RESET 으로 처음 위치로 돌립니다. 연동: TRAINING NO1/NO2 ENG TRNG → SIM 의 OEI 훈련 — 한쪽을 TRNG 로 올리면 그 엔진이 IDLE 로 줄고 남은 엔진이 2.5분 정격(MTA 의 73%) → 연속 정격(64%)까지 냅니다(PFD 에 OEI 2.5MIN 타이머와 ENG n TRNG, 3D 의 ENG 버튼도 ENGn TRNG). 둘 다 올리면 훈련이 걸리지 않고(AEO), 다 내리면 AEO 로 돌아옵니다.
    TQS(UPPER 창 아래 — 엔진 출력 조절장치): PCD 레버 둘(OFF · IDLE · FLY — 위치 글자 쪽을 누른다. FLY 에서 내리면 IDLE 에서 한 번 멈추고(누름쇠) 한 번 더 눌러야 OFF), MTRING 버튼, 엔진마다 FUEL(OPEN · CLOSE)과 T HANDLE(UNARMED · ARM). SIM 에서 엔진마다: PCD FLY → 출력 · IDLE → IDLE · OFF 또는 FUEL CLOSE 또는 T HANDLE ARM → 멎음. 한 엔진만 출력이면 OEI(2.5분 → 연속 정격), 둘 다 없으면 동력 없는 오토로테이션입니다(PFD 경고 ENG IDLE / ENG OFF). 3D 의 ENG 버튼(AEO · OEI · IDLE)도 그대로 씁니다. 그림 7 대로 SRCH LT · NAV LTS 는 NORM/IR, DISPLAY 는 DAY/NIGHT/NVG, APU/GPU 는 GPU/OFF/APU GEN(GPU 는 땅 위에서만 전원), TRAINING 은 NORM/TRNG 입니다.
    3D 화면의 계기 — 3D 지도가 떠 있으면(3D 단독 · 3D 탭 창 · 2D 지도 위 3D) 그 왼쪽 위에 PFD 의 계기(FCP 없이)가 겹쳐 뜹니다(3D 화면의 가로 1/4 · 높이 3/5 — 좁은 창에서는 읽을 만큼 키우고 비율대로 줄여 그립니다). 조작부 없이 비행에 몰입할 때 쓰십시오. 3D 창 오른쪽 위의 계기 ON / OFF 로 보이고 감춥니다(이 기기에 저장).
  • 활주로 평탄화 — 지도의 ICAO 공항 활주로 면(끝 너머 60m · 옆 30m 여유)은 공항표고로 평평합니다. 지형 자료는 활주로 위에서도 들쑥날쑥해 착륙·활주할 때 기체가 튀었습니다. 그 밖 150m 에 걸쳐 원래 땅으로 부드럽게 이어 턱이 지지 않습니다. 3D 지형 · SIM 의 땅 · 전파고도가 같은 높이를 씁니다. 활주로 좌표 자료가 없는 속초·울진은 공항 기준점 둘레(반지름 400m)를 폅니다.
  • 시작 비밀번호: 앱을 열면 먼저 비밀번호를 묻습니다. 맞게 넣으면 그 탭에서는 다시 묻지 않고 (새로고침해도 그대로), 앱을 새로 열면 다시 묻습니다. 화면 앞에서 막는 잠금이며 보안 장치는 아닙니다.
  • 시작 화면: 비밀번호를 넣으면 화면을 고릅니다 — PC 모드(지금처럼 PFD·지도·CDU 분할) · 3D 단독 모드(3D Only 로 바로 — 태블릿·휴대폰) · Simple Mode(창을 하나씩만 — 위쪽 줄의 PFD · 3D · MAP · CDU · UPPER · LOWER · SYSTEM 버튼으로 골라 보고, PC 모드 버튼으로 돌아갑니다) · SIM Mode(SIM 조종을 켜고 창 배치판을 띄웁니다 — PFD·FCP · 3D · MAP · CDU · UPPER · LOWER · SYSTEM 을 하나씩 눌러 화면마다 새 창으로 띄워 모니터마다 따로 놓습니다. 브라우저가 한 번 누를 때 창 하나만 열어 주므로 하나씩 누르고, 떠 있는 화면은 녹색으로 표시되며 한 번 더 누르면 본 창으로 돌아옵니다. 본 창은 시뮬을 돌리는 바탕이니 닫거나 최소화하지 마십시오. PFD 창 탭의 ⧉ 창 배치 로 언제든 다시 엽니다). 같은 탭에서 새로고침하면 고른 화면으로 다시 열립니다.
  • SIM 모드(FCP 1행 TDOWN·T/D to H 버튼 오른쪽 SIM 버튼): 조이스틱으로 직접 조종합니다. PFD 의 자세·속도·고도와 지도의 위치·항적이 함께 움직입니다.
    사이클릭 좌우 → 뱅크(최대 45°)와 선회, 사이클릭 전후 → 기수 자세(최대 60°), 페달 → 기수만 회전(최대 25°/s), 컬렉티브 → 토크(TQ %).
    자세 하나가 곧 속도입니다 — 고도를 지키며 날 때 수평 120kt · 기수 4° 80kt · 7.5° 호버(0kt)(4° 까지는 1° 당 10kt, 그 뒤 호버까지는 1° 당 약 23kt — 호버 언저리에서는 자세를 조금만 바꿔도 속도가 크게 바뀝니다), −10° 140kt(숙일 때 1° 당 2kt — 빨라질수록 항력이 급히 늘어 덜 늡니다). 7.5° 보다 더 들면 뒤로 갑니다. 오르내려도 같은 자세면 같은 속도로 수렴합니다(수평 120kt 는 1,000ft 로 오르는 중에도 수평 — 실제의 피토관 오차 같은 어긋남은 두지 않습니다).
    속도·고도는 점점 빠르게 바뀝니다 — 자세를 바꾸면 가감속이 처음엔 작다가 갈수록 커져 속도가 점점 가속되며 바뀝니다(일정한 빠르기로 바뀌지 않습니다 — 가속은 1초에 0.8kt/s 씩 오래 커집니다). 그 자세의 속도에 가까워져서야 짧게 풀려 넘쳐 지나치지 않습니다. 감속은 더 빨리 붙어 1초에 3kt/s 씩 최대 12kt/s(기수를 들면 원판을 젖혀 항력까지 받습니다), 가속은 제자리 3.5kt/s 에서 속도가 붙을수록 커져 40kt 부터 6.5kt/s(전이양력)까지 갑니다 (예: 120kt 에서 기수 10° 숙이면 1초마다 +0.4 · +1.2 · +2.0 · +2.8kt 로 붙음 / 동고도 120kt 에서 60kt 자세로 들면 감속 3 → 6 → 9 → 12kt/s 로 세져 8초면 60kt / 제자리에서 기수 5° 숙이면 10초에 36kt · 20초에 100kt). 자세가 가감속의 세기를 바꿉니다(위 한계·붙는 빠르기에 곱함) — 증속은 수평 ×1.0 · 기수 5° 숙임 ×1.2 · 10° 숙임 ×1.4(사이는 고르게) · 기수 들림 0~3° ×0.8 · 3~5° ×0.6 · 5~7.5° ×0.5, 감속은 기수 들림 0~3° ×1.2 · 3~5° ×1.3 · 5~10° ×1.5 · 10° 넘게 ×2.0.
    컬렉티브를 올리면 토크가 0.25초쯤에 따라붙고(1초에 최대 120% — 종전의 2배 빠르기), 상승률도 점점 빨라지며 붙습니다 — 상승·강하율이 바뀌는 빠르기는 1초에 최대 500fpm(최소·최대 상승률은 그대로)입니다.
    조종(컬렉티브·사이클릭)에 따른 속도·고도 변화 빠르기는 위 값의 90%입니다(종전보다 10% 느리게).
    자세는 위아래 48°(조종간 끝까지 — 종전 60° 의 80%로 좁혀 같은 움직임에 더 정밀) 까지 잡힙니다(속도는 뒤로 40kt · 앞으로 160kt 에서 멎습니다). 땅 위(바퀴형) — 토크를 20% 넘게 쓰면 천천히 앞으로 굴러가고(토크가 클수록), 사이클릭을 민 만큼 더 빨리 붙습니다(당기면 늦추고, 뒤로는 구르지 않습니다). 땅 위의 자세는 위아래 10° 까지이고, 토크를 20% 아래로 내리면 섭니다. 옆으로는 미끄러지지 않습니다.
    지면효과 · 호버 높이 — HOV(호버 파워, PERF 의 IGE 호버 토크)를 기준으로 HOV−10% 면 바퀴가 떨어져 3ft, HOV−5% 면 5ft, HOV 면 10ft 에서 호버링합니다(그 위는 로터 지름쯤에서 OGE 로 늘어납니다). HOV−20 ~ HOV−10% 는 바퀴가 떨어지기 직전이라 PFD 에 호박색 LIGHT ON WHEELS 가 뜹니다 (기본 PERF 에서 HOV 가 70% 라 50~60%). 땅 가까이에서는 상승률이 토크를 곧 따라가 그 높이를 지나쳐 출렁이지 않습니다.

    상승률 = 남는 토크 × 44fpm(레버 토크 − 그 속도의 필요 토크). 그래서 100% 토크면 제자리는 약 1,000fpm, Vy 는 약 2,300fpm, 고속에서는 다시 줄어듭니다. 모자라면 1% 당 38fpm 으로 내려갑니다(한계 상승 3,000 · 강하 4,000fpm). 이 값은 PERF 중량 16,000lb 기준이고 무게에 반비례합니다(남는 동력 ÷ 무게 — 20,000lb 면 80%). 필요 토크가 이미 무게·밀도고도를 담고 있어, 무겁고 덥고 높을수록 오토로테이션 강하율도 커집니다.

    SIM 을 켜면 지도 창이 3D 로 바뀌고 1인칭(조종석) 시야가 됩니다 — 눈이 헬기 자리에 놓이므로 화면에는 앞만 보입니다(뒤에서 따라가는 3인칭이 아닙니다).
    카메라가 헬기 자리·고도에 그대로 놓이고, 방향지시계대로 방위가, 자세계대로 기울기와 뱅크가 따라갑니다. 기본 시선은 저속(40kt 이하)에서 기체 자세보다 5° 아래라(함정 이착함 때 발밑 갑판이 잘 보이게) 수평 자세면 지평선이 화면 한가운데보다 조금 위이고, 속도가 붙을수록 덜 숙여 120kt 에서는 0° — 순항 수평 자세면 지평선이 한가운데로 와서 외부 시점(EXT)에서 본 기체 자세와 목측이 같습니다. 기수를 들면 그만큼 하늘을, 숙이면 땅을 봅니다(카메라 자체가 들리므로 앞으로 나가 보이지 않습니다). 뱅크를 주면 카메라가 그대로 기울어 지평선이 PFD 의 ADI 와 같은 쪽으로 기웁니다(오른쪽 뱅크면 지평선 오른쪽이 올라갑니다 · 확대되지 않습니다). 1인칭에서는 3D 축척과 제 마커(모형)를 숨기고, 대신 화면 아래 가운데에 내 헬기의 기수(nose)가 높이 1/10 만큼 보입니다(기체에 붙어 있으므로 자세가 바뀌어도 그 자리 · 둘러보기로 고개를 돌리면 비켜 갑니다).
    지형의 기복에 튀지 않습니다 — 3D 지형은 높이를 1.5배 과장해 그리고, 더 자세한 지형 타일이 들어올 때마다 높이가 조금씩 바뀝니다. 카메라(와 외부 시점의 헬기)는 그 차이를 천천히(1.5초) 따라가 산 위를 지나거나 타일이 바뀌는 순간에도 위아래로 튀지 않습니다. 땅 가까이(AGL 40m 아래)에서는 그려진 땅에 그대로 맞춰 내려앉고, 외부 시점의 카메라는 같은 프레임의 헬기 자리를 그대로 씁니다.
    MAP ON/OFF(CDU 버튼 아래) — 3D 단독 화면에서 2D 지도를 계기 칸과 같은 크기로 CDU 칸 왼쪽에 겹쳐 띄웁니다. 겹친 CDU 의 MAP 버튼도 이 지도를 켭니다(3D 단독은 그대로). MAP 단독 화면에서는 지도 아래 3D 버튼으로 3D 단독에 돌아갑니다.
    CDU ON/OFF(3D 오른쪽 버튼 묶음, 계기 버튼 아래) — 3D 단독(3D Only) 화면에서 CDU 를 3D 버튼 줄 바로 왼쪽에 계기 칸과 같은 높이(3/5)로 겹쳐 띄웁니다(너비는 CDU 비율대로 — 좌우 빈 여백 없이). CDU 창 그대로라 키·화면이 같고, 끄거나 단독을 나오면 제자리로 돌아갑니다(이 기기에 기억).
    STICK ON/OFF(FCP 버튼 아래) — SIM 모드의 3D 단독 화면에서 오른쪽 아래(R CHIN 자리)에 화면 조종간 셋을 띄웁니다: 컬렉티브(위아래 · 놓아도 그 자리 · 아래 0% … 위 140%)는 화면 왼쪽 아래 끝(왼손), 오른쪽 아래에는 페달(좌우 · 놓으면 가운데)과 사이클릭(원형 · 16방향으로 맞춰 민 만큼 · 끝까지 밀면 피치 ±10° · 롤 ±20°(트림 자세 위에) · 피치는 가운데 감도 반 · 놓으면 가운데 — 트림이 자세를 지킵니다). 켜면 R CHIN 창은 닫히고, 켤 때 컬렉티브는 지금 토크 자리에서 시작합니다. 실물 조종간과 함께 쓸 수 있습니다(화면 조종간을 쥔 동안은 그 값).
    GYRO ON/OFF · GYRO ALIGN(STICK 버튼 아래) — 태블릿·휴대폰을 기울여 사이클릭을 몹니다(SIM 3D 단독). GYRO ON 을 누르면 기울기 센서를 켜고(아이폰·아이패드는 허락을 묻습니다), GYRO ALIGN 을 누른 그때의 자세가 가운데가 되어 그때부터 조종합니다. 기기를 25° 기울이면 끝 — 화면 사이클릭과 같이 16방향 · 피치 ±10° · 롤 ±20°(피치는 가운데 감도 반)입니다. 화면 사이클릭을 손으로 쥐면 손이 앞서고, 화면을 가로·세로로 돌리면 다시 ALIGN 해야 합니다.
    FCP ON/OFF(3D 오른쪽 버튼 묶음) — 3D 단독(3D Only) 화면에서 PFD 소프트키(위) + FCP 패널(아래)을 3D 화면 왼쪽 아래에 한 창으로 띄웁니다 (화면 너비의 반 · 높이의 45% 안으로 줄여 그림). 버튼 그대로라 기능이 같고, 켜면 L CHIN 창은 닫힙니다. 분할 화면에서는 PFD 아래에 FCP 가 있으므로 열지 않습니다.
    CHIN BUBBLE — 1인칭에서는 정면 시야가 3D 창 가득 차고, 좌·우 발밑 창은 그 위 아래 왼쪽·오른쪽 모서리에 붙어 겹쳐 뜹니다(창 하나가 너비 약 1/3 · 높이 2/9). 가운데 앞쪽 아래는 가리지 않아 전방을 넓게 봅니다. 발밑 창은 헬기의 CHIN BUBBLE 처럼 정면보다 50° 아래를 좌·우로 15° 벌려 보며, 기체 자세를 따라 돕니다(고개 돌리기는 따르지 않습니다). 함정도 그려지므로 착함할 때 갑판을 내려다볼 수 있습니다. 3D 창 오른쪽 위 CHIN 버튼으로 끄고 켭니다.
    외부 시점(EXT) — CHIN 아래 EXT 버튼을 누르면 뒤에서 따라가며 내 헬기(흰수리)를 봅니다 (한 번 더 누르면 1인칭 · 조이스틱 버튼에 「외부 시점」을 배정할 수도 있습니다). 헬기 뒤 조금 위(12°)에서 기수 방향으로 내려다보고, 시야 둘러보기(B0 + 햇)로 ◀▶ 는 헬기 둘레를 돌고 ▲▼ 는 위아래로 오르내립니다(놓으면 다시 뒤로). 창이 좁으면 헬기 전체가 들어오게 그만큼 물러섭니다. 외부 시점에서는 CHIN 창을 닫고, SIM 을 나갔다 들어오면 1인칭부터 시작합니다. 바꿀 때는 0.9초 동안 카메라가 옮겨 갑니다 — EXT 로는 조종석 시선 그대로 뒤로 쑥 물러나며 헬기가 앞으로 나오고, 1인칭으로는 헬기 뒤에서 조종석으로 쑥 빨려 들어간 뒤 기수·CHIN 창이 나타납니다.
    흰수리 3D 모형 — 입면도·평면도·측면도를 바탕으로 실제 크기(전장 20m — 주로터 앞 끝에서 꼬리로터 뒤 끝까지)로 그립니다: 주로터 지름 14.1m · 꼬리로터 3m · 동체 약 18.8m, 흰 동체에 붉은 엔진 덮개, 뒤로 노랑 → 파랑 띠, 붉은 수평 꼬리날개(왼쪽에만), 꼬리로터는 오른쪽. 자세(기수·피치·뱅크)를 그대로 따르고 로터가 돕니다 (시뮬이 멈추면 멈춤). 바퀴 바닥이 지면 · 함정 갑판에 닿게 놓입니다. SIM 이 아닐 때 3D 지도에도 초록 삼각형 대신 이 모형이 보이며, 멀어서 작게 보일 때만 삼각형을 같이 띄웁니다.
    3D 화질(상·중·하) — 3D 창 오른쪽 위 화질 버튼을 누를 때마다 상 → 중 → 하 로 바뀝니다 (기본 중, 고른 값은 이 기기에 남습니다). 낮출수록 그리는 해상도와 받는 타일이 줄어 저고도에서도 부드럽습니다 — 상: 기기 해상도 · 사진 19 · 지형 15 단계 / 중: 1.25배 · 17 · 14 / 하: 0.8배 · 15 · 12. CHIN 창은 중에서 1초에 30번, 하에서 15번만 다시 그립니다.
    지형·사진은 20NM 안의 것을 들고 있습니다 — 3D 와 CHIN 창이 같은 타일을 함께 쓰고(한 번 받고 한 번 고친다), 20NM 안의 덜 자세한 단계와 발밑 4NM 의 지형은 미리 받아 둡니다. 20NM 밖으로 벗어난 것은 지웁니다.
    땅 위에서는 그려진 지형 위로 눈높이(8m)만큼 떠 있습니다. 끄면 원래 보던 창으로 되돌아옵니다.
    켤 때 AFCS(NAV·HDG·ALT·CRHT·GSPD·IAS)는 풀립니다. 켠 뒤 상위모드를 다시 걸면 그 축은 AFCS 가 몰고 조종간의 그 축 값은 무시합니다 — HDG·NAV 는 좌우(뱅크)와 페달을, ALT(선택 고도로 가는 것 포함)·CRHT 는 컬렉티브를 가져갑니다.
    SIM 의 ALT·CRHT 는 출력(토크)으로 고도를 지킵니다 — 고도를 곧바로 옮기지 않습니다. CRHT 중에도 기수를 숙이면 속도가 붙고, 운동에너지로 바뀐 만큼 고도가 빠지려 하면 토크를 더 써서 되찾습니다(80 → 120kt 가속에 약 20ft 빠졌다가 15초쯤에 돌아옴). 뱅크를 주면 늘어난 필요 토크만큼 더 씁니다. ALT 는 선택 상승률로 오르내려 선택 고도에 넘치지 않고 섭니다.
    IAS 는 기수 자세를 가져갑니다 — FCP 의 IAS 라벨을 누르면 지금 속도를 기준으로 켜지고 (다시 누르면 꺼집니다), IAS ▲▼ 는 기준을 1kt 씩 옮기며 켭니다. 켜져 있으면 ADI 가 그 속도를 내는 자세(수평 120kt · 4° 80kt · 7.5° 호버)로 잡히고 속도가 그 값에 섭니다 (오르내려도 그 자세 그대로). 조종간을 밀고 당기면 그만큼 자세가 벗어나고 속도도 따라 바뀌었다가, 놓으면 IAS 자세로 천천히(초당 5°) 돌아와 속도도 기준으로 돌아갑니다. 켜져 있는 동안 전후 트림은 기준 속도를 1kt 씩 옮기고, FORCE TRIM 은 지금 속도를 새 기준으로 잡습니다. PFD 속도계에 기준 속도(청록 벅과 숫자)가 나오고 FMA 의 IAS 가 초록으로 켜집니다. 끄면 그 자세를 트림으로 잡아 두어 튀지 않습니다. GSPD 를 걸면 IAS 는 풀립니다(GSPD 가 자세를 맡습니다). HDG 가 걸려 있는 동안 좌우 트림(4방향 비퍼 트림·조이스틱 햇)은 HDG 를 풀지 않고 선택 헤딩을 1° 씩 옮깁니다(누르고 있으면 0.5초 뒤부터 0.1초마다 1°). HDG 는 HDG 라벨을 한 번 더 누르면 풀리며 그 자리 뱅크를 이어 잡고, NAV·ALT·CRHT 는 버튼으로 풉니다(ALT·CRHT 를 풀면 그 상승률에서 레버가 이어 받습니다). 조이스틱 B1 은 상위모드 모두 해제입니다(NAV·HDG·ALT·CRHT·G/S·IAS·GSPD). 끄면 수평으로 돌아오고 종전 방식으로 돌아갑니다.
  • 전파고도(RA) — PFD 오른쪽 아래 CRHT 창은 기압고도가 아니라 전파고도(지면 위 높이 AGL)입니다. 지형 자료(T-CUT 과 같은 DEM)로 그 자리 땅 높이를 빼서 보이고(창의 RA 숫자), SIM 에서 함정 위에서는 갑판에서 잽니다. 바다 위에서는 기압고도와 같고, 산 위에서는 그만큼 낮게 읽힙니다(지형 자료를 아직 받지 못했으면 해수면 기준). CRHT 는 이 전파고도를 지킵니다 — 걸면 지금 RA 가 기준이 되고, 땅이 오르내리면 그만큼 따라 오르내립니다(500fpm 까지).
  • 승강계는 위로 3,000fpm, 아래로 4,000fpm 까지 읽습니다 — ±1,000fpm 까지는 반 칸에 넓게, 그 위는 좁혀 담습니다. SIM 에서 상승률은 토크 100% 에서 Vy 2,300fpm, 그보다 더 당기면(MTA 까지) 3,000fpm 까지 오르고, 강하는 4,000fpm 까지입니다.
  • ALT 버튼은 누른 순간의 고도를 기준으로 그 고도를 지킵니다(FMA ALT). 다른 고도로 가려면 ALT ▲▼ 로 기준을 옮깁니다 — 그 고도로 가는 동안 FMA 가 ALT.A(선택 상승률로)이고 닿으면 ALT 로 바뀝니다.
  • PFD 하단 FCP에서 IAS·HDG·CRS·VS·ALT·CRHT를 ▲▼/◀▶로 조절. CRHT ▲▼ 는 10ft 씩 옮기며, 지금 고도로 걸어 끝자리가 남아 있으면(예: 1,237ft) 먼저 10ft 단위로 맞춥니다(▲ 1,240 · ▼ 1,230). 스톱워치는 FCP 2행(BRG 오른쪽)에 있습니다. ALT·CRHT 는 IAS·HDG 처럼 글자를 누르면 그 모드가 걸리고(한 번 더 누르면 해제), 그 오른쪽 HHT ▲▼ 는 T/D to H 가 멈출 호버 높이(전파고도, 10ft 단위 · 기본 50ft)를 정합니다.
  • TDOWN(1행 HHT 오른쪽 위): 누르면 속도 80kt · 전파고도 200ft 로 기준만 바꿉니다 — IAS 80 · CRHT 200 이 걸리고 FMA 는 CRHT · IAS 입니다(SIM 밖에서도 같은 기준).
  • T/D to H(SIM 모드 · TDOWN 아래): 50kt 이상 · 전파고도 200ft 이상에서 누르면 FMA 컬렉티브·피치 축이 TDH — 지금 자리에서 3° 강하각으로 내려가며 속도를 0 으로 모아 HHT 높이에서 제자리 비행으로 멈춥니다 (남은 높이에 맞춰 지상속도를 일정 감속으로 줄이고, 강하율은 지상속도 × tan3° — 바람이 있어도 땅 위 한 점으로 내려갑니다). 다 내려오면 GSPD 0kt + CRHT(HHT) 로 넘겨 바람에 흘러가지 않고 그 자리에서 호버합니다. 롤 축은 HDG·NAV 가 그대로 몰다가 45kt 밑이면 FMA 가 황색(성능 감소 주의), 30kt 밑이면 롤 축을 놓습니다(decouple). 한 번 더 누르거나 ALT·CRHT·IAS·GSPD·G/A 를 걸면 풀립니다. 그동안 PFD 오른쪽 아래 높이 창이 HHT 로 바뀝니다.
  • 내활·외활 볼 — 자세계 맨 위 롤 지표 바로 위의 작은 관입니다. 볼이 가운데 두 선 사이에 있으면 협조 비행이고, 낮은 날개 쪽으로 가면 내활(slip) — 뱅크만큼 돌지 않음(저속 옆걸음 등), 선회 바깥쪽으로 가면 외활(skid) — 뱅크 없이 페달로 기수를 돌림입니다. 볼 쪽 페달을 밟으면 가운데로 돌아옵니다. 볼은 액체 속에서 구르듯 조금 늦게 따라옵니다.
  • HDG ◀▶는 기수를 즉시 돌리지 않고 선택 헤딩(HSI 청록 벅)만 옮깁니다. AFCS가 표준선회(360°/2분 = 3°/s)로 선회하며, 뱅크각은 속도의 16%로 자동 산출됩니다 (100kt → 16°). 목표에 가까워지면 자동 롤아웃합니다. HDG 가 걸려 있을 때 좌우 트림은 HDG 를 풀지 않고 선택 헤딩을 1° 씩 옮깁니다(NAV 가 잡고 있을 때는 제외).
  • IAS/HDG/CRS 라벨 버튼을 누르면 현재 값으로 즉시 동기화(CRS는 NAV 소스로 Direct-To). HDG 라벨은 IAS·ALT 버튼처럼 켜고 끕니다 — 누르면 지금 헤딩을 지키는 HDG 가 걸리고 (FMA 가운데 초록 HDG), 한 번 더 누르면 풀립니다(FMA 의 HDG 가 어두워짐 · 그 뱅크를 이어 잡음). NAV 가 걸려 있을 때 누르면 HDG 로 넘어갑니다.
  • 상위모드 모두 해제 — 조이스틱 B1(기본 배정). NAV·HDG·ALT·CRHT·G/S·IAS·GSPD 를 한꺼번에 풉니다. 이미 배정해 쓰던 조이스틱도 한 번 B1 을 이것으로 바꾸고, B1 에 있던 동작(예: GSPD)은 비어 있는 버튼(B8 · B10 · B11)으로 옮겨 둡니다. 설정 → 조종 장치 버튼 배정에서 바꿀 수 있습니다.

  • 글라이드 패스(G/S): GP 가 있는 ILS 주파수를 NAV1/NAV2 에 넣으면 승강계 왼편에 G/S 눈금과 자홍색 마름모가 뜹니다 — 마름모가 가운데 기준선보다 위에 있으면 강하선보다 높다는 뜻이고, 위아래 점은 각각 0.35° (최대편위 0.7° = 2점)입니다. 최대편위를 넘으면 마름모가 속이 빈 채 끝에 붙습니다.
    G/S 버튼은 없습니다 — ILS 를 지금 NAV 소스로 맞추면 스스로 무장(ARM)하고, 강하각에 맞는 순간 CAPT(자홍색)로 붙잡아 고도를 맡습니다 — 강하각과 지상속도에 맞는 강하율로 내려가며(3°·120kt ≈ 640fpm) 벗어난 만큼만 되돌립니다. 잡고 있는 동안에는 ALT·CRHT 유지가 물러납니다(고도를 두 곳에서 몰면 서로 싸웁니다). 신호를 잃거나(25NM 밖·안테나 뒤) ALT·CRHT·TDOWN·T/D to H·G/A 를 걸면 풀리고, 그 뒤에는 강하선에서 0.3° 넘게 벗어났다 돌아올 때 다시 잡습니다.

    강하선은 GP 안테나 자리에서 비행장 표고, 거기서부터 접근 방향으로 강하각만큼 올라가는 면으로 잡습니다. 강하각은 AIP 게재값이며(사천 24R 3.2° · 원주 3.3° 등), 비고에 없으면 3.0° 입니다. GP 가 없는 로컬라이저(대구 31R 등)에서는 뜨지 않습니다.
  • 로컬라이저(LOC): 지도 AWY 패널의 로컬라이저(LOC) 를 켜면 VOR 처럼 분홍 삼각형 + 식별부호·주파수로 표시됩니다(삼각형은 항공기가 들어오는 쪽을 가리킵니다). 눌러서 NAV1/NAV2 튜닝도 됩니다 — ILS 주파수를 넣으면 이제 국이 잡히고, 그 순간 OBS 코스가 게재 접근 코스로 맞춰집니다(로컬라이저는 코스가 시설에 붙어 있으므로). 안테나는 활주로 반대편 끝에 있습니다. 자료는 AIP AD 2.19 게재 좌표 그대로이며, 18개 공항 43개소입니다. AIP 에 접근 코스가 실리지 않은 곳은 같은 활주로 양끝 LOC 안테나를 잇는 방위에서 산출했고(±1°), 설명창에 (산출) 로 밝힙니다.

  • BRG 니들 · 지도 BRG 시현(PFD 소프트키 PFD Settings → Bearing1 · Bearing2 — FCP 의 BRG1 · BRG2 · #1BDP · #2BDP 버튼은 없앴습니다): 누를 때마다 OFF → NAV1 → NAV2 → FMS. 고른 국을 HSI 니들이 가리키고, 지도에도 그 니들의 선과 방위·거리 글자가 함께 나옵니다. 처음(고르기 전)은 니들만 있고 지도는 깨끗하며, OFF 면 니들 · 선 · 글자가 함께 사라집니다.

4. PFD · HOVER PAGE

  • PFD 배치(실기 PFD 형식): 자세계 하늘·땅이 위쪽 전체를 덮고, 그 위에 속도계(왼쪽 · 아래 GS 칸)와 고도계 + 승강계(오른쪽 · 위 RA 칸 — 2,500ft 위면 RA UP · 아래 QNH 칸)가 반투명으로 얹힙니다. 아래쪽은 땅 빛이 이어진 위에 왼쪽 엔진 파라미터(TGT · NG · TQ1/TQ2 · NP1/NR/NP2), 가운데 HSI, 오른쪽 레이더 고도계(CRHT) 테이프가 반투명으로 얹힙니다. HSI 나침반 중심은 자세계 중심과 같은 세로선이고, TAS · OAT · GS · ISA 는 HSI 왼쪽 아래에 한 줄에 하나씩 네 줄입니다. 엔진 파라미터의 TQ 막대에는 HOV · Vy · MTA 선이 그대로 있고, TGT · NG · NP 값은 지금은 토크·NR·엔진 상태(AEO/OEI/IDLE)에서 어림한 값입니다(엔진 모델은 차차 갖춥니다). 엔진이 돌면 NP 는 거버너가 100% 를 지키고, 레버를 내려 NR 이 넘치면 바늘이 갈라져 NR 만 오릅니다(출력을 넘겨 당겨 NR 이 처지면 NP 도 함께 처짐). NR 막대 띠는 자동회전 RPM 수정표(녹 88~110 · 황 84~88/110~114 · 적)입니다.
  • NAV SRC(PFD 소프트키 Active NAV — FCP 버튼은 없앴습니다): VOR1(NAV1) → VOR2(NAV2) → FMS. NAV1·NAV2는 CDU에서 튜닝한 VOR을 따라갑니다.
  • 접근절차 자동 튜닝 — 비행계획에서 접근절차를 불러오면(＋ ADD APPROACH) NAV1 은 그 공항의 VOR, NAV2 는 그 활주로의 LOC 주파수로 저절로 맞춥니다(알림으로 보여 줍니다). VOR 은 절차 경로에 든 VOR → 비행장 자료의 VOR(공항 25NM 안 — 주파수가 같은 먼 국은 잡지 않습니다) → 공항에서 가장 가까운 VOR(30NM 안) 순으로, LOC 는 절차 이름의 활주로(RWY 36R) → 같은 방향 → 그 공항의 다른 LOC 순으로 고릅니다. 맞출 국이 없으면 그대로 둡니다.
  • RNP: FCP 아래 줄. 4 / 2 / 1 / 0.3 NM — CDI 최대편위(스케일)를 정합니다.
  • MG (Slaved) / DG — 방향 기준(MAS). LOWER 창 AHRS 패널에서 정합니다: AHRS 노브(1 · N · 2 · BACKUP)가 PFD 에 쓰는 AHRS 를 고르고 (2 면 AHRS 2, 그 밖은 AHRS 1), 고른 AHRS 의 TG/MG DG 버튼이 들어가 있으면 DG · 나와 있으면 MG(Slaved) 입니다. DG 일 때 고른 AHRS 의 HIQ 노브를 돌리면 한 칸에 1° 씩 HSI 를 맞춥니다(노브는 다시 가운데로). 3D 창(FLY 아래)의 MG/DG 버튼과 −/+ 도 그대로 쓰고, 누르면 고른 AHRS 의 DG 버튼도 함께 바뀝니다(지도 창 버튼은 없앴습니다). MG (Slaved) — 방향 자이로를 지구 자기장에 늘 맞춥니다: HSI 가 지도와 꼭 맞습니다(처음 상태). DG — 방향 자이로만으로 방향을 정합니다: 지구 자전 등으로 1시간에 약 6° 씩 HSI 가 어긋나고 (비행 중에만 · 배속이면 그만큼 빨리), 버튼 아래 − / + 로 HSI 를 왼쪽 / 오른쪽 1° 씩 맞춥니다. 이때 3D 창 버튼 아래에 COMP(자기 나침반) 값이 보이니 그것과 견주어 맞추십시오. DG 이면 PFD 의 HDG 칸 왼쪽에 호박색 DG 가 뜹니다.
    HSI · HDG 칸 · HDG 유지(HDG 상위모드)는 이 계기 헤딩을 따르므로, 오차가 쌓인 채 HDG 로 날면 실제 기수는 그만큼 비껴 갑니다(예: 오차 −6° 면 HDG 090 으로 날아도 실제로는 096). 지도 · 3D · NAV(GPS 항법)는 실제 기수를 쓰므로 그대로 맞습니다. MG 로 돌아오면 곧 다시 자기 헤딩에 맞습니다.
  • SUSP(PFD 소프트키 — 넘어갈지 정할 자리에서 OBS 칸이 SUSP 로 바뀝니다 · FCP 버튼은 없앴습니다): 켜지면 칸 아래 녹색 바. 시퀀싱 보류 — 켜져 있으면 활성 웨이포인트를 지나도 다음으로 넘어가지 않고 그 구간의 코스를 계속 따라갑니다. 마지막 지점이어도 NAV 가 풀리지 않아, 홀딩이나 미스드어프로치를 계속 수행할 수 있습니다. 비행계획에 홀딩이 걸리면 저절로 켜지고(버튼에 「자동」 표시), 그만하고 다음 절차로 가려면 SUSP 를 눌러 풀면 곧바로 다음 지점으로 넘어갑니다. 손으로 켠 경우에는, 풀 때 지점을 이미 지나쳤으면 다음 지점으로 넘기고 아직 앞이면 그대로 그 지점으로 갑니다. RESET·CLR 하면 풀립니다.
  • SIM SPD: ×1 / ×2 / ×4 / ×8 배속(2×2 로 놓았습니다). 홀딩 한 바퀴 4분, 절차 하나 20분을 실시간으로 기다리지 않아도 됩니다. 시뮬 시간만 빨리 흐르고 계산은 그대로라 항적·진입·타이머가 실시간과 같습니다(프레임을 건너뛰지 않습니다). RESET 하면 ×1 로 돌아옵니다.
  • STOP WATCH: 시뮬 시간으로 갑니다 — 배속에 비례해 빨라지고 시뮬을 멈추면 함께 멈춥니다. 그래서 배속을 걸어도 이걸로 아웃바운드 1분·선회 시점을 그대로 잴 수 있습니다 (홀딩 레그 타이머와 같은 시간축). GPS 모드는 실제 비행이므로 실시간으로 갑니다. 위쪽 시각 표시는 언제나 실제 현재 시각입니다.
  • GSPD 작동 중에는 NAV·OBS 가 조향하지 못합니다. GSPD 는 요/롤 축을 가져가 (요 조작은 ANTI-TORQUE PEDAL 전용) 오토파일럿이 뱅크를 지령해도 기수가 돌지 않습니다. 이때 NAV·OBS 버튼은 빗금으로 흐리게 표시되고 FMA 는 GS·NAV대기로 바뀝니다. GSPD 를 끄면 그대로 이어서 조향합니다(설정은 유지).
  • NAV 오토파일럿: 코스선을 선택한 각도로 인터셉트한 뒤 롤아웃해 추종합니다. NAV 옆 45° 버튼으로 인터셉트 각도를 30 / 45 / 60° 중에서 고릅니다. 그 각으로 잡기에 표적이 너무 가까우면 표적으로 직행하며, 이때 FMA에 NAV DIR로 표시됩니다. 측풍에서는 편류수정각(WCA)을 자동으로 넣어 기수를 바람 쪽으로 틀고 대지트랙을 코스에 맞춥니다. VOR/LOC 소스일 때는 편위를 거리(NM)가 아닌 각도(최대편위 10°)로 보아 실제 수신기처럼 동작합니다.
  • 홀딩 패턴: CDU Flight Plan의 각 웨이포인트 행에 있는 HOLD 버튼으로 설정합니다. 선회방향(LEFT/RIGHT), 인바운드 코스(°M), 레그(TIME 30~180초 / DIST 1~20NM)를 고르고 ENTER 하면 지도에 노란 레이스트랙으로 그려집니다. NAV 오토파일럿이 그 웨이포인트를 활성으로 잡으면 자동 무장되고, FMA에는 HOLD ARM → 진입 후 HOLD D/P/T(진입 방식)로 표시됩니다. 홀딩 중에는 웨이포인트 시퀀싱이 멈추며, 빠져나가려면 DEL HOLD로 홀딩을 지웁니다.

  • 선회 선행: 웨이포인트에서 다음 레그로 꺾을 때 d = R·tan(θ/2) 만큼 미리 선회를 시작합니다 (R 은 지상속도·실제 뱅크 기준). VNAV 의 TOD 도 레그 방향 거리와 지상속도로 계산합니다.
  • 방위 표기는 모두 자북(°M)입니다 — HDG·CRS·BRG·NAV SOURCE·지도 BRG 라벨·비행계획 구간방위·바람·선박 침로. 지도의 선과 거리는 정확도를 위해 내부적으로 진북(대권) 기하로 계산하고, 화면 숫자와 입력만 자북으로 변환합니다 (한국 자기편차 9°W 기준). 측정자는 °T / °M을 함께 표시합니다.
  • NAV SOURCE 판독(오른쪽 아래 칸 — CRHT 계기를 2/3 높이로 줄이고 그 밑에 둠, HSI 와 겹치지 않음): FMS · NAV1 · NAV2 세 소스가 각각 가리키는 지점의 명칭 · 방위 · 거리를 소스마다 두 줄(윗줄 소스·명칭, 아랫줄 방위·거리)로 동시에 표시합니다. 현재 선택된 소스는 배경 강조로 구분되며, 좌우의 BRG1 · BRG2 판독을 모두 대신합니다 — 같은 값을 두 번 적지 않습니다. 나침반의 BRG1(파랑) · BRG2(녹색) 니들은 그대로이고, 하단 BRG 버튼으로 켜고 끕니다.
  • 순서 바꾸기: 비행계획 목록에서 각 줄 왼쪽의 ≡ 손잡이를 끌어서 순서를 바꿉니다 (터치·마우스 모두 됩니다). 놓으면 번호가 1,2,3… 로 다시 매겨지고, 활성 웨이포인트는 자리가 아니라 그 지점을 따라갑니다. 손잡이 밖을 누르면 종전대로 웨이포인트 카드가 열립니다.
  • CRS 라벨을 누르면 지금 자리로: PFD 의 CRS 글자를 누르면 코스선이 지금 있는 자리를 지나도록 다시 잡힙니다(FMS 는 활성 웨이포인트, VOR 은 그 국 기준). 먼 거리에서 코스선이 항공기를 비켜 가던 것을 바로잡았습니다 — 대권의 방위는 양 끝에서 다르므로(수렴각), 지점에서 잰 방위로 코스를 잡아야 선이 정확히 항공기를 지납니다 (80NM 에서 약 1.1NM 어긋났습니다).
  • Direct To 는 언제든 다시: 이미 활성인 지점이어도 버튼을 누르면 지금 있는 자리에서 그 지점으로 코스를 다시 잡습니다(코스에서 밀려난 뒤 「여기서 다시 곧장」 이 필요한 때를 위해서입니다). 이렇게 잡은 구간의 레그 코스는 항공기를 따라 계속 다시 잡힙니다 — 카드에 「레그 코스 · 현 위치」 로 적히고, 카드를 열어 둔 채 날면 값이 따라 움직입니다. 늘 현재 위치를 지나는 선이므로 이 구간에서는 CDI 편차가 0 입니다(코스를 정해 두고 인터셉트하려면 왼쪽 진입 코스를 쓰거나 FCP 의 CRS 로 코스를 정하십시오 — 그때는 코스가 굳고 편차가 살아납니다). 비행계획을 따라 다음 지점으로 넘어가면 종전대로 구간(leg) 코스로 돌아갑니다.
  • 진입 코스(웨이포인트 카드): Direct To 버튼이 반으로 나뉘어, 왼쪽에서 그 지점으로 향해 들어갈 방위(°M)를 직접 넣습니다 — OBS 모드처럼 접근 방향을 골라서 들어갈 수 있습니다. 누르면 아래 빈 자리에 숫자판이 펴지고(값 칸은 그대로 보입니다), ENT 하면 그 지점이 활성이 되며 CDI · 지도 코스선 · NAV 오토파일럿이 모두 그 선을 씁니다. 비우고 ENT 하면 해제되어 앞 지점에서 이어지는 레그 코스로 돌아갑니다. 오른쪽은 종전 그대로 ➤ Direct To — 지금 자리에서 곧장 그 지점으로 갑니다.

  • 출발지(ORIGIN)를 넣으면 항공기가 그 자리로 갑니다. 비행계획의 첫 웨이포인트를 공항 명칭·좌표 어느 방법으로 넣든(나중에 고쳐도) 항공기가 그 지점에 섭니다 — 다른 공항에서 출발해 보려고 지도를 끌어다 옮길 필요가 없습니다. 두 번째 웨이포인트부터는 옮기지 않습니다. 비행 중이면 옮길지 되묻고, GPS 모드에서는 옮기지 않습니다(위치는 수신기가 정합니다).

DEFAULT 는 저장한 가운데를 지우고 기본값(손을 뗀 지금 자리)으로 돌립니다. 칸 아래에 조종 장치 · 저장 여부 · 지금 CYC · PEDAL · COLLECTIVE 값이 보입니다. (FCP 의 HOCAS · CTR 버튼은 이 칸으로 옮겼고, FCP 는 HOVER 글씨로 돌아왔습니다.)
  • HOVER PAGE(80kt 미만): 호버 속도·위치 지시. 좌측 HOVER 그룹의 HOVER PAGE / HOVER POS 사각 버튼으로 켜고, 기준 속도는 트림 옆 원형 GSPD 버튼으로 잡습니다(실제 조종간 배치에 맞춘 위치). SIM 에서 GSPD 가 걸려 있을 때 트림을 거슬러 조종간을 밀면(against trim) 그쪽으로 지상속도가 붙습니다 — 끝까지 밀면 초당 10.5kt(종전의 세 배). 놓으면 기준속도로 돌아가고, FORCE TRIM 을 누르면 그 순간의 속도가 새 기준이 됩니다.
  • G/A(FORCE TRIM 아래, SIM 모드): 누르면 FMA 컬렉티브·피치 축이 GA — 두 단계로 갑니다. ① 40kt 미만이면 기수를 지금 자세에서 7.5° 숙여 증속하고, 컬렉티브는 고도가 떨어지지 않게만 씁니다. ② 40kt 를 넘으면(넘어서 눌렀으면 곧바로) 선택 상승률(기본 1000fpm, VS ▲▼ 로 최저 300fpm)로 오르며 속도는 Vy 로 수렴합니다(Vy~VNE 면 지금 속도 유지, VNE 초과면 VNE). 상승률은 8초에 걸쳐 붙고 속도가 목표에 다가갈수록 늘어납니다. 목표 속도에 닿고 상승률이 다 붙으면 컬렉티브 VS · 피치 IAS 로 넘어갑니다. 어느 단계든 누른 고도 아래로는 내려가지 않습니다. 롤 축은 커플되지 않으므로 뱅크는 그대로 — 기수 유지가 필요하면 조종사가 HDG 를 겁니다.
  • HOVER PAGE에는 SHIP(청록)과 비행계획 활성 웨이포인트(빨강 삼각형)가 함께 표시됩니다. 반경 50 ft 이내면 실제 축척 위치에, 밖이면 방향 니들과 점선으로 나타납니다.
  • ANTI-TORQUE PEDAL ◀▶(GSPD 우측): 뱅크 없이 기수만 즉시 회전(홀드 시 약 12°/s). GSPD 작동 중에는 HDG 화살표가 기수와 분리되므로 요 조작은 이 페달로 합니다.
  • COLLECTIVE TRIM ▲▼(4-way 트림 좌측): 현재는 VS ▲▼와 같은 동작(±100 fpm)입니다. 4-way 트림은 사이클릭, 페달은 요, 컬렉티브는 파워를 맡는 수동 조작 구성으로 확장하기 위한 배치입니다.
  • 지도에 SHIP이 켜져 있으면 호버 페이지에 선박 상대위치가 표시됩니다(멀면 니들, 50ft 이내면 실제 위치).
  • T-CUT: 전방 20NM 지형 단면. 현재 고도가 화면 중앙에 오고 지형이 상대적으로 움직입니다.
  • ⟳ HOLD: 홀딩 진입 판정 레이어. 홀딩 픽스를 중심으로 직진 / 평행 / 눈물방울 구역을 자북 기준으로 칠하고, 픽스에서 본 항공기 방위(어느 방향에서 들어오는가)가 어느 구역에 있는지 항공기 기호로 표시합니다. 판정·방위·픽스까지 거리·기수와 바람 보정 기수(인바운드/아웃바운드)를 함께 읽어 줍니다. 비행계획에 홀딩이 아직 활성이 아니어도(예정) 미리 볼 수 있습니다. 홀딩은 FPL → 웨이포인트 → HOLD 에서 넣습니다.

  • Checklist: KUH-1CG 정상·특수·비상 절차(계통별), 이전/다음 이동.
  • 웨이포인트 좌표 산출(Flight Plan → Add WPT): BRG / DIST는 참조점에서 지정한 자북 방위(라디얼)로 지정 거리만큼 나아간 지점을, BRG / BRG는 두 참조점의 방위선이 만나는 지점을 대권 기하로 계산해 웨이포인트로 만듭니다. 참조점은 VOR · AIP 픽스 · 공항 · 현재 비행계획 WP 중에서 고르며(카테고리 필터 + 이름 검색, 현 위치에서 가까운 순), 산출 좌표는 확정 전에 DMS·십진수·현 위치 기준 방위/거리로 미리 보여줍니다. 이름은 SEL270/20, SEL/TGU 처럼 자동으로 붙습니다. BRG/BRG 는 교차각이 10° 미만이면 거부하고 30° 미만이면 경고합니다 (얕은 각도에서는 방위 1°가 좌표를 크게 흔듭니다).

7. GPS 모드 (실비행)

  • GPS 버튼을 켜면 실제 위치·속도·고도로 계기가 움직입니다. 앱을 열면 GPS 는 꺼져 있습니다.

10. 조이스틱 / 게임패드

  • USB·블루투스로 연결한 뒤 이 창을 클릭해 앞으로 가져오고, 아무 버튼이나 한 번 누르면 인식됩니다(브라우저는 첫 입력이 있어야 장치를 알려 줍니다).
  • 인식이 안 될 때: ① 장치의 X-input / D-input 모드 스위치를 D-input 으로 — X-input 은 윈도우 전용이라 맥에서는 값이 올라오지 않는 기종이 많습니다(PXN 계열 등). ② 창을 클릭해 포커스를 준 뒤 버튼을 누릅니다. ③ 아래 입력 진단에 장치 이름이 뜨는지 확인합니다 — 이름이 뜨는데 값이 안 움직이면 ①번입니다.
  • 스틱 하나가 여러 대로 잡히는 기종(복합 HID)에서는 값을 내는 장치로 자동으로 옮겨 붙습니다. 진단에 연결된 장치가 모두 나오고 사용 중인 것에 ←사용 이 붙습니다.
  • 설정 → 조종 장치 버튼 배정에서 동작을 누르면 입력 대기가 되고, 그때 누른 버튼이 그 동작에 잡힙니다. 배정은 기기에 저장되어 다음에도 그대로입니다.
  • 배정할 수 있는 동작: FLY/PAUSE · FORCE TRIM · G/S·GSPD(지상속도) · HOVER POSITION, 트림 ▲▼◀▶ · 페달, HDG · IAS · ALT · CRHT · VS · CRS 증감, ALT/CRHT 유지 · NAV · SUSP · OBS, HOVER PAGE, 지도 추종 · HDG↑/N↑ · 확대/축소.
  • 동작 성격에 따라 누르는 순간 한 번(FLY/PAUSE 등), 누르는 동안 유지(트림), 누르고 있으면 연속(HDG·IAS 등, 화면 버튼과 같은 리듬)으로 동작합니다.
  • 햇(HAT) 스위치: 8방향 햇을 축 하나로 올려 보내는 기종(대개 축 9)은 ▲▶▼◀ 네 방향으로 풀어 각각 배정합니다. 쉬는 자리가 범위 밖(3.2857)인 기종은 물론, 0 에서 쉬는 기종도 8등분 격자값으로 알아봅니다. 대각은 이웃한 두 방향이 함께 걸립니다 (예: ▲▶ 를 밀면 전방 트림 + 우 트림). 화면에는 햇 9 ▲ 처럼 표시됩니다.
  • 일반 아날로그 축은 ＋/− 방향별로 잡을 수 있고, 쉬는 자리가 0 이 아닌 장치(정지 상태 −1 등)도 연결 시점 값을 중립으로 잡아 오작동하지 않습니다.
  • 장치를 뽑거나 창이 뒤로 가면 누르고 있던 동작은 자동으로 풀립니다.
  • 안드로이드: 조종 장치의 버튼을 게임패드 버튼이 아니라 키로 넘기는 기종이 많습니다 (축·햇만 잡히고 버튼은 조용한 증상). 그런 버튼도 그대로 배정할 수 있고 키 F13 처럼 표시됩니다. 배정한 키만 듣기 때문에 기존 키보드 단축키와 다투지 않습니다.
  • 아이패드 · 아이폰: 이 기기는 브라우저 이름과 상관없이 모두 사파리(WebKit) 엔진이라 크롬을 깔아도 직접 연결(WebHID)이 없습니다. 여기서는 게임패드로 인식되는 컨트롤러 (Xbox · PS · MFi)를 쓰거나, 키보드처럼 잡히는 장치를 키로 배정해 쓰십시오. 같은 장치라도 맥 · 윈도우 · 안드로이드의 크롬에서는 직접 연결이 됩니다.
  • 맥에서 게임패드로 아예 안 잡힐 때: 배정 화면의 🔌 장치 직접 연결(WebHID) 을 누르고 목록에서 장치를 고르십시오. 브라우저가 게임패드로 보여 주지 않는 장치도 직접 열어 씁니다 (Chrome · Edge. 한 번 허락하면 다음부터 자동으로 다시 연결됩니다).
  • 입력 진단: 배정 화면 아래에 지금 들어오는 버튼 번호와 축 값이 그대로 나옵니다. 잡히지 않는 입력이 무엇으로 올라오는지 여기서 확인할 수 있습니다 (HAT 로 표시된 축은 8방향 햇으로 풀어 씁니다).
※ 아직 버튼만 연동합니다. 사이클릭·컬렉티브·페달의 아날로그 축을 직접 조종하는 기능은 넣지 않았습니다(현재 비행 모델이 AFCS 목표값 기반입니다).
※ 숫자·트림 키는 누르고 있으면 연속 조작됩니다. 입력창 타이핑 중에는 동작하지 않습니다.
